Setting it up

  • Use "Copy signature", not the HTML code, when your headshot is an uploaded file — pasting is what gets the image into the mail client properly.
  • Gmail: Settings → See all settings → Signature → paste with Ctrl/Cmd+V. Gmail re-hosts the image on its own servers.
  • Outlook on the web: Settings → Mail → Compose and reply → paste into the signature box.
  • Outlook desktop: File → Options → Mail → Signatures → paste. Outlook saves the image locally and attaches it to each message.
  • Check the preview tabs above — dark mode and blocked images are where signatures usually fall apart, and both take a second to look at.
  • Send yourself a test — to a phone and to an Outlook account — before the whole team switches over.
